# Contributing

Please read [our Code of Conduct](CODE_OF_CONDUCT.md). Issues and pull requests
are welcome for bugs, accessibility, performance, cultural evidence and game
interaction. Include reproduction steps and expected/actual behavior for bugs.

For code changes, run `npm run typecheck`, `npm test` and `npm run build`.
Keep changes focused and explain user-visible behavior and validation. Add a
meaningful regression test for a logic bug; avoid tests that merely repeat code.

Do not commit personal data, credentials, original scans, research archives or
media without verified redistribution rights. Keep historical evidence separate
from game invention. Document an asset's license and source before adding it.

By submitting project-authored code, you agree to make that contribution available
under the project's MIT license. Clearly identify any separately licensed material.
